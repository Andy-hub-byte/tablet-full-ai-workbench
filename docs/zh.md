## 1. 三分钟上手

### 1.1 打开方式（任选其一）

| 方式 | 操作 | 适合场景 |
|---|---|---|
| 在线演示 | 浏览器打开 <https://andy-hub-byte.github.io/tablet-full-ai-workbench/> | 想立刻体验 |
| 单文件 | 下载 `index.html`，双击打开 | 离线使用 / 发给朋友 |
| 克隆仓库 | `git clone` 后双击 `index.html`，或 `python3 -m http.server 8000` | 二次开发 |

> 三种方式功能完全一致。整个应用只有一个 HTML 文件，没有任何外部请求，断网也能用（AI 聊天模块需要能访问你所配置的模型接口）。

### 1.2 界面导览

- 顶部导航：🎵 音乐 / 💻 代码 / 🤖 AI 聊天 / 📝 记事本 / ⏱️ 计时器，点击即切换；
- 右上角：⭐ 跳转 GitHub 仓库，🌙 / ☀️ 切换深色 / 浅色模式（自动记忆）。

## 2. 音乐播放器详解

### 2.1 添加音乐

三种方式任选：

1. 点击「＋ 上传音频」按钮，多选本地文件；
2. 把音频文件**拖拽**到左侧歌单区域；
3. 没有音频文件？点击「🎶 演示音轨」，应用会在浏览器里**实时合成**一段 WAV 音乐（约 8 秒），用来体验播放器功能。

支持 MP3 / WAV / OGG / FLAC / M4A / AAC 等浏览器可解码格式。

### 2.2 播放控制

| 操作 | 说明 |
|---|---|
| 点击歌单某一行 | 播放该歌曲；点击当前正在播放的行 = 暂停 / 继续 |
| ⏮ / ⏭ | 上一首 / 下一首 |
| ▶ / ⏸ 大圆钮 | 播放 / 暂停 |
| 进度条 | **按住拖动**可跳转进度（触屏友好） |
| 🔊 图标 + 滑块 | 静音切换与音量调节 |
| 🔁 / 🔂 / 🔀 | 播放模式循环切换：列表循环 → 单曲循环 → 随机播放 |

播放时歌单中当前歌曲会显示跳动的音量条动画，封面也会有呼吸效果。

### 2.3 其他能力

- **锁屏 / 系统媒体控制**：手机上播放时，锁屏界面和通知栏会出现播放控件（基于 Media Session API）；
- **移除歌曲**：点击歌单行右侧的 ✕；
- **刷新后歌单为空是正常现象**：浏览器安全策略不允许网页把本地文件写入磁盘，你的文件不会被上传，刷新后需重新添加（文本类数据如记事本不受影响）。

## 3. 代码编辑器详解

### 3.1 基础功能

- **语法高亮**：支持 C++ / C，实时渲染，无需等待；
- **行号**：左侧 gutter 自动生成，滚动同步；
- **Tab 缩进**：按 Tab 插入两个空格；行尾是 `{` `(` `:` `[` 时按 Enter 会自动多缩进一级；
- **字体大小**：`A−` / `A＋` 按钮调节（11px ~ 22px）；
- **模板 / 复制 / 下载 / 清空**：工具栏一键操作，下载格式为 `.cpp`。

### 3.2 触屏符号键盘（平板 / 手机重点功能）

点击「⌨️ 符号键盘」展开 33 个大按钮：`{ } ( ) [ ] ; : , . " ' = + - * / % < > ! & | ^ ~ # \ _ @ ? $` 以及 Tab、空格。

- 点击括号类符号会**成对插入**，光标自动落在括号中间；
- 如果先选中了一段文字再点括号，会用括号把选中内容包起来；
- 再点一次「⌨️ 符号键盘」或「收起键盘」即可关闭。

> 这个功能专门解决平板 / 手机输入 C++ 代码时符号难找的问题。

### 3.3 快捷键与操作技巧

| 操作 | 效果 |
|---|---|
| `Tab` | 插入缩进（两个空格） |
| `Enter` | 换行并自动对齐上一行缩进 |
| `Shift + Enter` | 普通换行，不自动缩进 |
| 点击「插入模板」 | 填入一段示例 C++ 程序（含注释，适合试高亮效果） |

## 4. AI 聊天与 Agent 详解

### 4.1 这个模块是什么

一个**运行在浏览器里的 AI 聊天窗口**，可以接入任意 OpenAI 兼容接口，包括：

- 本机 **Ollama**（完全离线，推荐）；
- 本机 **LM Studio**（离线）；
- 任何 OpenAI 兼容云 API（自备 Key）。

与普通聊天窗口不同的是：它带 **Agent 能力** —— AI 可以调用内置工具，**直接操作这个工具箱**。

### 4.2 配置模型（30 秒）

1. 点击聊天面板右上角「⚙️ 模型设置」；
2. 点一个预设按钮自动填充（也可手动填写）：

| 预设 | Base URL | API Key | 模型示例 |
|---|---|---|---|
| 🖥 本地 Ollama | `http://localhost:11434/v1` | 随意填，如 `ollama` | `qwen2.5:3b` |
| 🖥 LM Studio | `http://localhost:1234/v1` | 随意填，如 `lm-studio` | `local-model` |
| ☁️ OpenAI 兼容 | `https://api.openai.com/v1` | 你的真实 Key | `gpt-4o-mini` |

3. 点「🔍 获取模型列表」拉取可用模型（可选）；
4. 点「💾 保存设置」，开始对话。

> 所有配置只保存在你自己浏览器的 localStorage，不经过任何服务器。

### 4.3 本地 Ollama 完整示例

```bash
# 1. 安装 Ollama（https://ollama.com）后：
ollama pull qwen2.5:3b     # 下载模型（约 2GB，可按需换 gemma3、qwen3 等）
ollama serve               # 启动服务，默认监听 11434 端口

# 2. 打开工具箱 → AI 聊天 → 模型设置：
#    Base URL: http://localhost:11434/v1
#    API Key : ollama（任意非空即可）
#    模型名称 : qwen2.5:3b
```

Ollama 较新版本原生支持 function calling，工具调用走标准协议；旧版本或某些小模型不支持时，应用会自动切换到「```tool JSON 代码块」回退协议（系统提示词中已内置规则），两种路径都已内置。

### 4.4 Agent 工具列表

| 工具名 | 参数 | 效果 |
|---|---|---|
| `notepad_write` | `content` | 把内容写入记事本（覆盖） |
| `notepad_read` | 无 | 读取记事本当前内容 |
| `timer_start` | `seconds`、`label` | 开始倒计时并提示 |
| `music_play` | `query` | 按歌名关键词播放 |
| `music_control` | `pause/resume/next/prev` | 暂停 / 继续 / 切歌 |
| `switch_app` | `music/code/chat/notes/timer` | 切换到指定界面 |
| `get_current_time` | 无 | 返回当前日期时间 |

### 4.5 试试这些指令

- 「帮我在记事本里列一份周末采购清单」
- 「5 分钟后提醒我起来喝水」
- 「播放歌单里第一首歌」
- 「现在几点了？顺便把今天的日期记到记事本」
- 「切到计时器界面，帮我设一个 25 分钟的番茄钟」

每次工具调用都会以虚线气泡展示**工具名、参数、执行结果**，执行过程透明可见。

### 4.6 没有模型也想看效果？

打开页面后按 `F12` 打开控制台，执行：

```js
TFAW.seedChatDemo()
```

会用一段预设对话演示完整的「用户提问 → 三次工具调用 → 总结回复」流程，无需任何 API Key。

### 4.7 生成控制

- `Enter` 发送，`Shift + Enter` 换行（兼容中文输入法）；
- 生成过程中点「⏹ 停止」可中断；
- 「清空对话」会同时清空上下文历史。

## 5. 记事本详解

- **自动保存**：停止输入约 0.4 秒后自动写入 localStorage，刷新 / 关闭浏览器不丢失；
- **字数统计**：左下角实时显示；
- **导出 .txt**：右上角一键下载，文件名带时间戳；
- **清空**：需二次确认；
- 注意：无痕模式 / 清理浏览器数据会导致内容丢失，重要内容请及时导出。

## 6. 计时器详解

### 6.1 倒计时

- 手动输入「时 / 分 / 秒」，或点快捷预设：1 / 3 / 5 / 10 / 25 分钟（25 分钟即经典番茄钟 🍅）；
- 点「▶ 开始」启动，按钮变为「⏸ 暂停」；「↺ 重置」回到设定值；
- SVG 圆环随时间收缩，结束时圆环变红并播放三声提示音（WebAudio 实时合成，仓库里没有音频文件）；
- 运行期间**浏览器标签标题**会同步显示剩余时间，切到别的标签也能看到。

### 6.2 正计时

点「⏱ 正计时」切换：从 0 开始计时，每分钟圆环走满一圈。适合记录一段时长，不用于闹钟提醒。

## 7. 平板 / 手机使用技巧

1. **浏览器选择**：安卓平板推荐 Chrome / Edge；iPad 用 Safari。均已验证；
2. **横屏使用代码编辑器**：竖屏时编辑器高度自适应，横屏可视区域更大；
3. **符号键盘**：写 C++ 代码务必打开「⌨️ 符号键盘」，比系统键盘快得多；
4. **播放本地音乐**：平板上点「上传音频」后在文件选择器里挑歌即可，文件不会离开设备；
5. **单手操作**：底部大按钮（播放、开始计时）都做了加大处理；
6. **深浅色**：晚上用深色更护眼，一键切换，偏好会被记住；
7. **断网可用**：除 AI 聊天需要访问模型接口外，其余功能完全离线。

## 8. 部署指南

### 8.1 GitHub Pages（本项目演示站用的就是它）

1. Fork 或 Push 本仓库到你的 GitHub；
2. 仓库页面 → **Settings → Pages → Build and deployment → Source** 选 `Deploy from a branch`；
3. Branch 选 `main`，目录选 `/`，Save；
4. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/tablet-full-ai-workbench/`。

### 8.2 其他静态托管

因为是纯静态单文件，可直接扔到任何静态托管：Netlify、Vercel、Cloudflare Pages、阿里云 OSS、腾讯云 COS、Nginx…… 把 `index.html` 放到根目录即可。

### 8.3 完全离线

把 `index.html` 拷到手机 / 平板 / U 盘，用浏览器打开即用。AI 聊天若配合本机 Ollama，可做到全程不联网。

## 9. 二次开发指南

### 9.1 代码结构（单文件，按注释分区）

`index.html` 内部分为 9 个区域，均有中文注释标题：

| 区域 | 内容 |
|---|---|
| 0. 通用工具函数 | `$`、`esc`、`toast`、`fmtTime`、`downloadFile` 等 |
| 1. 主题切换 | `applyTheme()`，CSS 变量驱动 |
| 2. 模块切换 | `switchApp()` |
| 3. 音乐播放器 | `addFiles()` / `playIndex()` / `renderPlaylist()` / `makeDemoWav()` |
| 4. 代码编辑器 | `highlightCode()` / `updateEditor()` / 符号键盘 |
| 5. AI 聊天 | `AGENT_TOOLS` / `streamChat()` / `runAgentLoop()` / `runTool()` |
| 6. 记事本 | `saveNotes()` |
| 7. 计时器 | `startCountdown()` / `toggleTimer()` / `playBeep()` |
| 8. 对外接口 | `window.TFAW` |

### 9.2 改主题色

所有颜色都是 CSS 变量，改 `:root`（深色）和 `:root[data-theme="light"]`（浅色）里的 `--accent` 等变量即可全站生效：

```css
:root{
  --accent:#5b8cff;        /* 主题色：按钮、高亮、进度条 */
  --accent-soft:rgba(91,140,255,.14);  /* 主题色浅底 */
  --bg:#0b0e14;            /* 页面背景 */
  --surface:#151a26;       /* 卡片背景 */
  /* …… */
}
```

### 9.3 给 Agent 加一个新工具

两步，以「随机决定吃什么」为例：

1. 在 `AGENT_TOOLS` 数组里加定义（发给模型的 Schema）：

```js
{ type:'function', function:{
  name:'what_to_eat',
  description:'随机推荐一道菜',
  parameters:{ type:'object', properties:{ meal:{ type:'string', enum:['breakfast','lunch','dinner'] } } } } }
```

2. 在 `runTool()` 的 `switch` 里加分支：

```js
case 'what_to_eat': {
  const menu = ['红烧肉','番茄炒蛋','宫保鸡丁','牛肉面','沙拉'];
  return '推荐：' + menu[Math.floor(Math.random()*menu.length)];
}
```

保存刷新即可，无需构建。

### 9.4 加一个新模块（比如「单位换算」）

1. 复制一个 `<section class="app" id="app-xxx">…</section>` 结构；
2. 在顶部 `#tabs` 里加一个 `<button class="tab" data-app="xxx">🧮<span>换算</span></button>`；
3. 如果需要 AI 能操作它，再按 9.3 加对应工具。

### 9.5 控制台调试接口

页面暴露了 `window.TFAW`：

```js
TFAW.version          // 版本号
TFAW.switchApp('code')
TFAW.addDemoTrack()   // 生成一首演示音轨
TFAW.setCodeSample()  // 填入示例代码
TFAW.seedChatDemo()   // 演示 Agent 对话
TFAW.notes.set('你好')  // 写记事本
TFAW.music            // 播放器状态（歌单、当前曲目）
TFAW.audio            // 原生 audio 元素
```

## 10. 常见问题速查

| 问题 | 答案 |
|---|---|
| 刷新后歌单空了 | 正常，浏览器不允许网页保存本地文件，重新添加即可 |
| AI 请求报 `Failed to fetch` | 检查 Base URL；本地服务是否启动；是否跨域（CORS） |
| 报 `HTTP 404` | Base URL 通常要以 `/v1` 结尾 |
| 演示页连不上本地 Ollama | https 页面不能访问 http 接口，请本地以 `http://localhost` 打开页面 |
| iOS 不自动播放 |  Safari 策略，先点一次播放即可 |
| 记事本丢失 | 无痕模式或清理了数据，重要内容请导出 .txt |
| 想改主题色 | 见 [9.2](#92-改主题色) |

更多报错与解法见 [README FAQ](../README.md#-常见问题-faq)。
