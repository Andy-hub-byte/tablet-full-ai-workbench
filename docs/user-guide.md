## 1. 开始对话

1. 平板浏览器打开 **http://localhost:8080**
2. 首次进入是注册页，注册的第一个账号自动成为**管理员**
3. 顶部下拉框选择模型：
   - `workbench-agent` —— 默认 Agent 人格模型（推荐）
   - `qwen:1.8b` —— 原始基础模型
4. 在底部输入框输入问题，点击发送

对话是流式输出的，可以随时点击「停止」按钮中断生成。

## 2. Agent 智能体：工具 / 规划 / 记忆

### 2.1 启用工具

部署脚本已自动导入 5 个工具。在对话界面：

1. 点击输入框上方的「**集成**」图标（拼图/插头样式）
2. 勾选需要启用的工具：
   - ☑️ 代码运行工具
   - ☑️ 任务规划工具
   - ☑️ 长期记忆工具
   - ☑️ 联网搜索工具
   - ☑️ 设备状态工具
3. 保存后，AI 会在需要时自动调用这些工具

### 2.2 五个工具能做什么

| 工具 | 对话中这样说 | 效果 |
|---|---|---|
| 代码运行 | 「帮我写个 C++ 冒泡排序并运行一下」 | AI 写代码 → g++ 编译 → 运行 → 展示输出和报错 |
| 任务规划 | 「帮我规划一下本周学习 C++ 的计划」 | 生成步骤清单，保存在本地，可随时更新进度 |
| 长期记忆 | 「记住我喜欢用表格总结知识」 | 写入本地记忆库，之后的对话都会参考 |
| 联网搜索 | 「查一下 Qwen 最新版本是多少」 | DuckDuckGo 搜索并总结结果 |
| 设备状态 | 「现在平板内存还剩多少？」 | 显示内存/存储/模型列表 |

### 2.3 任务规划示例

```
你：帮我把「用 C++ 写一个记事本程序」拆解成步骤
AI：（调用任务规划工具，生成清单）
    1. 搭建菜单界面（显示/新增/删除/退出）  [待办]
    2. 实现记事本存储结构                  [待办]
    3. 实现各菜单功能                      [待办]
    4. 编译测试并修复问题                  [待办]

你：第一步完成了
AI：（调用工具更新步骤状态）✅ 步骤 1 已完成，进度 1/4
```

### 2.4 长期记忆示例

```
你：记住：我是初中生，正在学 C++，请用浅显的语言解释
AI：好的，已保存到长期记忆 ✅
（之后的每次对话都会自动参考这条偏好）
```

### 2.5 关于模型能力的重要提示

- 1.8B 小模型**工具调用能力有限**，可能出现不调用工具或参数错误
- 想要稳定的 Agent 体验，请切换更大模型：
  ```bash
  ollama pull qwen2.5:3b     # 约 2GB，6GB 内存平板可流畅运行
  ollama pull qwen2.5:7b     # 约 4.7GB，建议 12GB 内存
  ```
- 代码相关任务推荐 `qwen2.5-coder:3b`（代码专用微调模型）

## 3. 代码编辑器 Code Studio

打开 **http://localhost:8899** ，界面分为：

```
┌───────────────────────────────────────────────┐
│ 语言: [C++ ▾]  模型: [workbench-agent ▾]       │
│ [▶ 运行] [✨AI生成] [💡AI解释] [🔧AI修复] [清空] │
├──────────────────────────┬────────────────────┤
│                          │  ▸ 运行输出         │
│   代码编辑区              │  ▸ 错误信息         │
│   （CodeMirror）          │                    │
│                          │  退出码: 0  耗时35ms │
└──────────────────────────┴────────────────────┘
```

### 3.1 手动敲代码

左侧编辑区直接输入，支持语法高亮、自动缩进。
快捷键 **Ctrl+Enter** 运行。

### 3.2 AI 生成代码

1. 点击「✨ AI 生成」
2. 输入需求，例如：「写一个 C++ 程序，输入10个数输出最大值」
3. AI 生成的代码自动填入编辑器

### 3.3 AI 解释 / AI 修复

- 「💡 AI 解释」：逐行讲解当前代码的功能和语法，面向初学者
- 「🔧 AI 修复」：自动找出代码错误，给出修复版本和修改说明

### 3.4 一键运行

点击「▶ 运行」：

- **C++**：自动调用 `g++ -O2 -std=c++17` 编译后运行
- **Python**：调用 `python3` 运行
- **JavaScript**：调用 `node` 运行
- **HTML**：生成实时预览页面，点击「打开预览」查看
- **Shell**：调用 `/bin/sh` 运行

右侧显示标准输出、标准错误、退出码和耗时。
死循环代码会在 30 秒后自动终止。

## 4. 模型管理：切换与下载

```bash
ollama list                    # 已安装模型
ollama pull qwen2.5:3b         # 下载新模型（自动出现在网页模型列表）
ollama rm qwen:1.8b            # 删除模型
ollama run qwen:1.8b           # 命令行直接对话（测试用）
```

按平板内存选择模型：

| 平板内存 | 推荐模型 | 体积 |
|---|---|---|
| 4GB | `qwen:0.5b` / `qwen:1.8b` | 0.4~1.1GB |
| 6GB | `qwen2.5:3b` / `qwen2.5-coder:3b` | 约 2GB |
| 8GB | `qwen3:4b` / `gemma3:4b` | 约 2.5~3.3GB |
| 12GB+ | `qwen2.5:7b` | 约 4.7GB |

完整清单（含说明）见 [models.json](../ollama/models.json)。

## 5. 导入 LoRA 微调模型

### 5.1 交互式导入（推荐）

```bash
bash ollama/import-lora.sh
```

按提示输入：

- LoRA 适配器文件路径（GGUF 格式，如 `~/Download/my-lora.gguf`）
- 基础模型（默认 `qwen:1.8b`，**必须与训练时的基座一致**）
- 新模型名称（如 `my-coder`）

脚本会自动生成 Modelfile 并执行 `ollama create`，完成后即可在网页模型列表中看到。

### 5.2 手动导入

1. 编辑模板文件 `ollama/Modelfile.lora-template`：

   ```
   FROM qwen:1.8b
   ADAPTER /root/workbench/ollama/adapters/my-lora.gguf
   ```

2. 创建模型：

   ```bash
   ollama create my-lora-model -f Modelfile.lora-template
   ```

### 5.3 注意事项

- 适配器必须与基础模型**同架构同基座**（Qwen1.5 的 LoRA 必须配 `qwen:1.8b`）
- Safetensors 格式的适配器目录也可以直接导入，见模板文件注释
- 用 unsloth / LLaMA-Factory 等框架微调后，用 llama.cpp 的
  `convert_lora_to_gguf.py` 转成 GGUF 再导入
- 导入后可用 `ollama run my-lora-model` 测试，`/show info` 查看 Adapter 信息

## 6. 多人对话房间

基于 Open WebUI 的 **Channels（频道）** 功能：

1. **创建账号**：管理员登录 → 右上角头像 → 管理员面板 → 用户 → 添加用户
   （为家庭成员分别创建账号）
2. **创建房间**：左侧边栏 → 「频道 Channels」→ 新建频道（如「家庭群」「学习小组」）
   → 邀请成员加入
3. **加入房间**：同一 Wi-Fi 下，其他设备浏览器打开
   `http://<平板IP>:8080`（IP 可用 `bash scripts/status.sh` 查看），登录自己的账号

频道内支持：

- 实时文字聊天（多人同时在线）
- @ 提及成员
- 在频道中直接 @ 机器人提问，调用本地模型回答
- 历史消息持久保存

## 7. 触屏使用技巧

- 所有按钮均 ≥48px，戴手套/粗手指也能准确点击
- 对话界面底部输入框固定，配合平板键盘单手可达
- 代码编辑器支持双指缩放页面（浏览器设置中开启）
- 横屏使用时编辑区与输出区左右分栏，效率更高
- 下拉刷新式交互已适配，无需悬停操作
